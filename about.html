    关于本站#

    Lumen · 星皓书房 是一个自托管的个人数字图书馆：原地读取 Calibre 书库，配一间 Koodo 级的阅读器。完整说明、部署方式与技术取舍见 GitHub 仓库。

    这个站点是它的门面与读书笔记：首页是产品介绍；书架、笔记、论文与参考都用 Markdown 写成，由 Hugo 与 Hugo Book 主题生成，发布在 GitHub Pages。支持 KaTeX 数学公式与 pseudocode.js 伪代码。

    命名#

    星皓书房：星，是书架上散落的每一个光点；皓，明亮；书房，是读书的那间屋子——合起来是一间被星光照亮的书房。

    英文名 Lumen 取自拉丁语「光」，也是国际单位制中光通量的单位。它不收藏书，它把书点亮。
