    定义与定理#

    定义局域化长度
    在无序系统中，波函数包络按 $\psi(r) \sim e^{-|r|/\xi}$ 衰减，$\xi$ 称为局域化长度。$\xi$ 有限对应局域态，$\xi \to \infty$ 对应扩展态。
    定理标度理论

    电导 $g(L)$ 随系统尺寸 $L$ 的变化只依赖于 $g$ 本身：

    $$ \beta(g) = \frac{d \ln g}{d \ln L} $$

    $\beta(g)$ 的符号决定系统在热力学极限下是金属还是绝缘体。

    例题与解答#

    例题例2-1 一维链的能带宽度

    一维紧束缚链的色散为 $E(k) = -2t \cos(ka)$，求能带宽度。

    $E(k)$ 在 $k=0$ 取最小值 $-2t$，在 $k=\pi/a$ 取最大值 $2t$，故带宽 $W = 4t$。

    import numpy as np

def tight_binding_band(k, t=1.0, a=1.0):
    """一维紧束缚链的色散关系"""
    return -2 * t * np.cos(k * a)
