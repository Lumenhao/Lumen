这是一篇示例笔记，用来演示笔记板块的样子。首页的「最近笔记」会自动列出最新 5 篇。

## 笔记怎么放

新建一个 Markdown 文件放到 `content/notes/` 下，文件名就是网址：

```
content/notes/my-note.md  →  /notes/my-note.html
```

## 和书的区别

- **书**：有封面、目录、章节，按顺序读，放在 `content/books/<分类>/<书名>/`
- **笔记**：单篇成文，按时间倒序列出，放在 `content/notes/`

笔记同样支持数学公式：$e^{i\pi} + 1 = 0$，也支持代码块、表格和提示框。
