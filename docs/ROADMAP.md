# 路线图

原则：先把「读得下去」做透，再扩展功能面。每个里程碑都必须能独立部署、可回滚。

## M0 · 静态书房（已完成）

- Hugo + hugo-book 主题，封面墙、书籍详情、自动书架、深浅色主题
- 公版演示书与使用说明
- GitHub Actions 自动发布到 GitHub Pages

## M1 · 阅读优先 MVP（已完成）

**目标**：指向一个 Calibre 库就能读，阅读体验对标 Koodo。

- [x] Calibre `metadata.db` 只读接入（书籍/作者/系列/标签/出版社/评分/语言/简介/格式/封面）
- [x] 书架页：封面墙、搜索、标签与系列筛选、排序、分页
- [x] 书籍详情：元数据、简介、格式下载、开始阅读
- [x] EPUB 阅读器：分页/滚动、目录、四套主题、字号/行距/字体/页边距、进度恢复
- [x] 划线高亮与笔记、书签、全文搜索、键盘与触摸翻页
- [x] 进度/书签/笔记持久化（独立 SQLite）
- [x] Docker Compose 部署
- [x] 公版书演示库生成脚本

**验收**：见 [PRODUCT.md](PRODUCT.md#5-优先级与路线)。

## M2 · 管理与格式

- 上传入库：拖拽上传 → 写入 Calibre 目录 → `calibredb add`（可选，检测到 Calibre CLI 时启用）
- 格式转换：EPUB ⇄ MOBI/AZW3、PDF → EPUB（调用 `ebook-convert`，后台任务 + 进度）
- 元数据轻编辑：标题、作者、标签、评分、简介（写回 Calibre，带备份）
- 回收站：软删除 + 恢复 + 彻底删除
- PDF 阅读器：pdf.js，页码进度、缩放、双页
- 漫画：CBZ 按页阅读与页码进度

## M3 · 多用户与生态

- 账号：本地账号 + 会话，管理员/读者/访客三种角色
- 权限：书库可见性、私藏书、访客只读开关
- 跨端进度合并：以最后写入为准，记录来源设备
- OPDS 1.2：外部阅读器（KOReader / Readest / Moke）浏览与下载
- 设备推送：Kindle 邮箱推送
- 公开笔记：同书读者可见的评论与回复（沿用 talebook 的私有默认规则）

## M4 · 打磨与导出

- 全文搜索改为服务端索引（预建倒排，支持大库）
- 阅读统计与阅读历史
- 个性化书架：最近在读、系列归并、标签云
- 静态站导出：把书架导出为 Hugo 内容目录，静态展示与自托管共用元数据
- TTS 朗读与翻译
- 静态书房从仓库根目录迁移到 `site/`，形成「应用 + 展示」双目录

## 不做

- 书源爬虫、盗版聚合、公共书库运营
- DRM 破解
- 在 Web 端重建 Calibre 的完整元数据编辑能力
- 自研桌面/移动客户端
