Lumen · 星皓书房 是一个自托管的个人数字图书馆。它以你已有的 Calibre 书库为地基，一行元数据都不改； 再用一间 Koodo 级的阅读器，把 EPUB 与 PDF 读回书该有的样子。进度、笔记与书签，只留在你自己的机器上。

Interface

书架的秩序，阅读器的安静。

书库一屏尽览：封面墙、进度、元数据，搜索随打随出。点进去，是可以真正读下去的排版——分页或滚动、单栏或双栏，字距与行高都听你的。

Capabilities

该有的都有，不该动的都不动。

不重建书库、不改写元数据、不替你决定书该放在哪。Lumen 只做一件事：把你已经整理好的藏书，变成一个读得舒服的地方。

Calibre 只读接入

以只读方式打开 metadata.db，作者、系列、标签、评分全部原样读入。你的书库目录一个字节都不会被改写。

Koodo 级阅读器

基于 epub.js 的排版引擎：四套主题、衬线与黑体两套字体、字号行距字距可调，支持键盘翻页与目录跳转，PDF 也能顺滑翻看。

划线 · 笔记 · 书签

选中文字即可划线，四色标注；笔记与想法随手记下，书签一处收藏。全部存进你本地的 SQLite，随时导出。

全书搜索

在整本 EPUB 里检索原文，命中位置按章节列出，点一下直接跳回书中的那一行，不必再靠印象翻找。

进度跟随

阅读位置精确到段落，换浏览器、换设备打开都能接上。书架上的进度条，始终诚实。

一条命令部署

Docker 镜像带健康检查，compose 一键起停。笔记本、NAS、树莓派都能常驻，重建容器数据不丢。

Deploy

三条命令，书房开张。

只需要一台装着 Docker 的机器。默认接入仓库自带的演示书库，要读自己的书，改一行路径就够了。

  1. 找到你的 Calibre 书库 就是 metadata.db 所在的那个目录。Lumen 只读挂载它，不会写入任何内容。
  2. 写下书库路径 在仓库根目录新建 .env，填入 CALIBRE_PATH。Windows 盘符照原样写即可。
  3. 启动，然后打开浏览器 访问 http://localhost:8080。书库随即点亮，进度与笔记开始单独存放。
bash — lumen
# 1. 获取代码
$ git clone https://github.com/Lumenhao/Lumen.git
$ cd lumen

# 2. 指向你的 Calibre 书库
$ echo "CALIBRE_PATH=D:/Calibre Library" > .env

# 3. 启动
$ docker compose up -d
